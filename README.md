# 巡检任务与测量网关

本地演练资料使用虚构的实物、机构和记录编号。经营单据存放于 `data/`，包括 `orders.json`、`calibration.json`、`handoffs.json`。来源原件在提供时由资料端送出。

## 资料约定

线路距离和设备读数均用整数米。区段左闭右开，最后一段包含线路终点；站位校准点间按两锚定义的一次标定换算。覆盖用任务单给出的观测格点，质量为 usable 的定位观测命中格点才计数，一条观测只属一个区段。目录按世代列出保留、写入中和已回收的页，ttl 是离网关下一次覆盖还有几轮；额度由设备和交班轮次分别给出，所有页请求均计额度。补校准明确 supersedes 的卡才替换，时段和适用设备见卡。各资料的登记轮次是资料可知时间。

根路径列出资料入口。各路径每次请求依次返回该路径的演练响应，最后一条响应保持不变。不同路径有各自的请求计数。重启资料端从首条响应开始。路径清单中的链接相对同一服务。非演练路由的原件对应 `originals/` 下同名路径，经营单据也可以从 `/data/文件名.json` 直接领取。

## 运行资料端

运行依赖为 Python 3.11 标准库。

```sh
python3 source_service.py --port 8040
```

以下命令核对本地资料服务和交互。

```sh
python3 -m unittest discover -s tests -v
```
